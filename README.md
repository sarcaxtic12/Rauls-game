# Forno Rush — Wood-Fired Artisanal Trattoria

A hyper-realistic, calm, multi-room Neapolitan pizzeria time-management game built with HTML5 Canvas, procedural textures, and ASMR-inspired Web Audio synthesis.

## Features
- **Living 2.5D Dining Room**: Articulated guests walk in from the street, take seats at 3–6 tables, browse menus, get greeted for hospitality bonuses, eat steaming pizzas slice-by-slice, and leave cash & tips to collect and bus.
- **Physical Cook-Line Makeline**: Chilled brushed-steel GN pans filled with proofed dough, San Marzano Marinara, Genovese Pesto, Truffle Garlic White, fior di latte mozzarella, and 9 handcrafted toppings — grab and drag straight onto the Calacatta marble slab.
- **Wood-Fired Forno & Walnut Cutting Pass**: Live oak-fire hearths with Golden/Crispy/Burn gauges, swipe-to-slice walnut board, Sicilian Aranciata sodas, and a 3-slot Serving Pass.
- **Always-On Peripheral Monitor Bar**: Switch freely between Dining Room (`F1`), Cook Line (`F2`), and Wood-Fired Forno (`F3` / `Tab`) while keeping an eye on live mini oven progress bars, seated tables, and ready pies.
- **Trattoria Customization Showroom**: Earn coins and Prestige Rank to upgrade flooring, table linens, lighting, greenery & wine racks, signature oven domes, and kitchen capacity.

## Run Locally
```bash
npm start
```
Then open `http://127.0.0.1:3456` in your browser (or open `index.html` directly).
